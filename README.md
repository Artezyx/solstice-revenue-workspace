# Solstice — Revenue Workspace

React 19 / TypeScript interactive sales operations dashboard.

## Features
- Create opportunities
- Move deals through sales stages
- View total pipeline and probability-weighted revenue forecast
- Responsive layout

## Run
```bash
npm install
npm run dev
npm run build
```
This is a self-contained **frontend demo** with in-memory state. Backend API, NestJS, PostgreSQL, authentication and persistence from the larger project plan are **not included** in this initial GitHub version.
